# Changelog

## 0.2.0

- Import VS Code theme JSON directly by default, including JSONC and relative includes.
- Use theme names from JSON throughout the CLI; import T3 Code JSON with `--format t3`.
- Pick themes interactively, shuffle them, or select them by name.
- Add, replace, and remove custom themes without bundling personal presets.
- Preserve existing custom palettes and selection history.
- Show the theme directory in `--help` and provide JSON output for scripts.
- Verify clean package initialization in CI on macOS and Linux.
